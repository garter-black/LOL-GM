# LOL-GM 기존 승인 규칙 이관 감사표 — 비규범 자료

> 이 문서는 게임 규칙을 정의하지 않는다. [확정 규정집](rulebook/README.md)으로 옮기기 위해 과거 승인 기록의 **이관 범위**를 추적한다. 이슈의 기획·일부 구현·미확정 제안이 한 본문에 섞여 있으므로 **이슈 전체를 확정 규칙으로 간주하지 않는다**. 각 조항은 최종 사용자 승인/철회 및 후속 규정과 대조해야 한다.
>
> **2026-11-01 현재 편찬 상태:** 기존 96개 조항에서 [확정 UI 규칙 UI-009/010 및 일정·승강 CAL-009~011·COMP-016~017](RULEBOOK_APPROVAL_ADJUDICATION_2026_11_01.md) 이관으로 **103개 조항**이 되었다. 직접 댓글 링크 47개·이슈 수준 또는 기타 링크 56개이며, 이것은 출처 깊이 집계이지 승인 완료 판정이 아니다.
>
> **2026-11-01 최신 조사 범위:** 39개 일반 이슈의 610개 댓글을 출처 단위로 색인([4개 분할 목록](rulebook-audit/README.md)). **색인 완료는 각 선택의 현재 효력 판정·전부 룰북 수록과 다르다.** 원본 대조에서 #190A 실명 병행의 후속 철회, 다구단 소유 금지의 후속 B안 역전 등 중요 오류를 발견해 v0.2.1에 정정했다.
>
> **2026-11-01 2차 조사 범위:** 아래 19개 주요 소유 이슈의 본문·검증 사례/일부 #251 사용자 승인 댓글의 상위 규칙을 직접 대조했다. 해당 이슈의 **전체 댓글·최종 승인 수백 건을 1개씩 모두 판정하거나 전수 이관한 것은 아니다**. 따라서 미수록 항목을 미승인이라고 선언하지 않는다.

## 2026-11-01 시장·계약 예외의 승인 원문 링크 보강

[#321 승인 후속 댓글](https://github.com/lkh0802a/LOL-GM/issues/321#issuecomment-6465317390)에서 12월 첫째 화요일 개장·정확한 28일, 통합 시장 중 실경기 금지 및 연중 FA·미라이선스 바이아웃 예외를 직접 대조하여 **CAL-001/002/003, TRANS-001/004/005** 여섯 조항의 출처 링크를 보완하였다. 기존 의미 변경 없이 이관 근거의 추적성을 개선하였으며, **직접 댓글 링크 29개 조항 / 이슈 수준 또는 기타 링크 67개 조항**으로 집계를 갱신하였다. 나머지는 사용자 후속 승인·철회 확인 전까지 확정·폐기 상태를 임의 변경하지 않는다.

## 이후 이관/정정의 유효성 기준

1. 개별 사용자 **명시 승인**과 가장 최신의 **철회/보류**를 확인한다. 이슈의 제목이나 설계 제안을 곧바로 확정으로 간주하지 않는다.
2. 이미 수록된 같은 뜻의 조항은 **중복 ID로 추가하지 않고 기존 조항의 승인 근거만 보완**한다.
3. 실제 승인되었으나 규정집에 없는 항목은 **한 분야 파일에 새 고유 ID로 이관**하고 [CHANGELOG](rulebook/CHANGELOG.md)에 최초 이관/의미 변경 여부를 구별해 남긴다.
4. 게임 속 사무국의 미래 시즌 선택·임기 수치·이적시장 추가 개방 등 미확정/가변 사항은 별도 규정의 유효 시각과 권한만 수록한다.
5. 룰북에 일부만 실려 있더라도 **미이관 기존 사용자 확정 규정은 여전히 유효**하다. 룰북 누락은 제도 폐기나 새 승인 요청의 근거가 아니다.
