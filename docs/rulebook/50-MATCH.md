# 50. 경기·밴픽·스크림·패치

### MATCH-001 · 실제 5:5 게임과 단일 경기 결과
공식 경기·독립 대회·스크림·랭크의 실제 결과는 유효한 게임/경기 원본과 규정에서 확정한다. 경기 승패를 고정 OVR 확률이나 가짜 후속 결과로 대체하거나 두 경기 엔진이 동일한 결과를 따로 작성하게 하지 않는다. 선수 행동·전술·자원·전투·건물/승리조건의 실제 효과를 반영한다. [근거 #233](https://github.com/lkh0802a/LOL-GM/issues/233), [#241](https://github.com/lkh0802a/LOL-GM/issues/241)

### MATCH-002 · Fearless Draft 불변
시리즈에 적용되는 **Fearless Draft의 유효 규칙과 이전 세트 챔피언 사용 이력**은 영구 보존한다. 사무국·대회 포맷 AI·패치가 임의 해제하거나 우회할 수 없다. [근거 #311](https://github.com/lkh0802a/LOL-GM/issues/311), [#234](https://github.com/lkh0802a/LOL-GM/issues/234)

### MATCH-003 · First Selection 불변
**First Selection**의 유효한 선후 선택권과 밴픽 적용 절차도 일반적인 사무국 변경 대상이 아니다. 당시 시리즈·세트에서 확정된 권리와 드래프트 결과를 보존한다. [근거 #311](https://github.com/lkh0802a/LOL-GM/issues/311)

### MATCH-004 · 세트 사이 선수 교체
Bo3·Bo5에서 **세트 사이** 합법적인 등록 선수 교체는 허용하지만, **진행 중인 한 세트에서 선수 교체는 불허**한다. [근거 #251 #21A 재확인](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6244488968)

### MATCH-005 · 스크림의 실재성과 비공개
스크림은 실제 두 팀의 수락·유효 시간·선수 점유·연습 목적과 경기 로그를 기준으로 운영한다. 두 구단의 상호 동의 없는 전략/비공개 스크림 자료 공개는 불가하다. 세트 간 전술·선수·챔피언 실험은 적법 범위에서 가능하고, 중단 시 이미 완료한 세트의 이력·자원을 지우거나 미실시 세트를 승패로 조작하지 않는다. [근거 #251 #38~43](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6244488968)

### MATCH-006 · 원격 스크림
해외 구단과 원격 스크림을 할 수 있고 **지역 간 네트워크 핑/지연 차이를 게임 내 경기 페널티로 적용하지 않는다**. 다만 시차·팀 수락·선수 일정·회복·실제 이동 점유는 유지한다. [근거 #251 #44 수정](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6244488968)

### MATCH-007 · 패치 적용과 과거 경기
패치의 예정안·확정·실제 적용은 구별한다. 글로벌 패치가 실제 적용되면 **통합 랭크도 즉시 해당 패치**를 사용하지만, 공식 대회는 **그 대회에 잠긴 pinned patch**를 준수한다. 과거 경기·스크림 기록을 나중 패치로 소급 재계산하지 않는다. [근거 #232](https://github.com/lkh0802a/LOL-GM/issues/232), [#251 #35A](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6244488968)

### MATCH-008 · 핫픽스 시각
근거 있는 심각한 실제 밸런스 붕괴에 대응하는 핫픽스는 **발견 당일 예정된 공식 경기들이 모두 종료된 후** 적용한다. 진행 중인 Bo 시리즈의 다음 세트부터 임의로 즉시 적용하지 않는다. 기술적 방송 사고·가상 버그 이벤트를 핫픽스 근거로 창작하지 않는다. [근거 #232 최신 최종](https://github.com/lkh0802a/LOL-GM/issues/232)

### MATCH-009 · 실제 정보가 전술·판단에 미치는 효과
감독·AI 구단의 전술·상대 준비·밴픽은 실제 합법 정보, 선수 숙련·활동, 당시 패치와 팀 자원·상대 관측에 근거한다. 숨은 미래 결과·비공개 스크림 정답/확정 승률 버프를 입력으로 사용하지 않는다. [근거 #235](https://github.com/lkh0802a/LOL-GM/issues/235), [#280](https://github.com/lkh0802a/LOL-GM/issues/280)
