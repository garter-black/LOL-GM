# 80. 감독 UI·분석·뉴스·저장 관리

### UI-001 · 모바일 우선 정보·행동 분리
LOL-GM의 주된 사용 환경은 **모바일**이며 화면에서 **목록 탐색 → 상세 비교·판단 → 실제 감독 행동**을 구분한다. 승인된 계약·선수·출전·재정 옵션을 단순화 명목으로 제거하지 않고, 합법적인 세계 명령을 재사용한다. [근거 #225](https://github.com/lkh0802a/LOL-GM/issues/225), [#240](https://github.com/lkh0802a/LOL-GM/issues/240)

### UI-002 · 저장 슬롯의 선택적 안전 삭제
저장 슬롯은 시작·게임 내 목록에서 **불러오기와 구별된 명시적 삭제**가 가능해야 한다. 삭제 전 대상 슬롯/팀/시즌 확인·취소를 제공하며, 확정된 삭제가 이전 비동기 저장으로 복구되거나 **다른 슬롯을 삭제하는 일은 없어야 한다**. 삭제·읽기·내보내기/복구를 혼동하지 않는다. [근거 #273](https://github.com/lkh0802a/LOL-GM/issues/273)

### UI-003 · 실제 계약·영입 미리보기는 읽기 전용
선수 이적 관심도·수락 가능성·로스터 합류 후 배치·급여/바이아웃·지급 일정을 **관측 근거에 따른 미리보기**로 보여준다. 실제 영입 제안/수락/이적료·로스터 변경은 **명시적 제출·확정 전에는 일어나지 않는다**. 예측치와 실제 선수의 법적 동의를 구별한다. [근거 #225](https://github.com/lkh0802a/LOL-GM/issues/225), [#322](https://github.com/lkh0802a/LOL-GM/issues/322)

### UI-004 · 협상 과정과 약속·기한 표시
선수의 실제 요구, 명확한 거절/역제안·기한, 경쟁 구단의 합법적 공개 정보, **체결된 계약 약속의 이행/미이행 상태**를 동일한 사건 기록에서 추적한다. 즉시 거절 사유를 알림으로 확인할 수 있으나, 존재하지 않는 제안·경쟁 구단·계약 체결 사실을 허위로 생성하지 않는다. [근거 #225](https://github.com/lkh0802a/LOL-GM/issues/225)

### UI-005 · 스카우팅은 필요한 시점의 수요 기반 추천
실제 로스터 공석·계약 만료·전력 부족 등에 따른 **보강 후보**는 관련 화면에서 참고할 수 있지만, 과거에 제안되었던 **매주 유망주 보고·특별 발견 알림·반복 수집 배지**의 도입 결정은 철회되었다. 후보 열람·무시 자체에는 비용이나 벌칙이 없으며 유료 조사·영입은 감독의 명시적 선택이다. [근거 #251 최종 스카우팅 철회](https://github.com/lkh0802a/LOL-GM/issues/251)

### UI-006 · 실제 경기·계약·여론 정보의 출처 구분
게임 뉴스·대회 분석·시즌 평가·언론 보도에는 **그 시점에 존재한 실제 세계 사건/관측 근거**가 있어야 한다. 확인된 사실, 관측에 근거한 추론, 미확인 루머, 실제 계약 완료를 구분하며 미래 결과·타 구단 비공개 입찰·허위 경기/영입을 사실처럼 발표하지 않는다. [근거 #280](https://github.com/lkh0802a/LOL-GM/issues/280), [#322](https://github.com/lkh0802a/LOL-GM/issues/322)

### UI-007 · 과거 경기 복기와 결과 설명
전술·밴픽·선수 기량에 관한 해설/복기·사후 피드백은 **실제 실행된 경기/당시 관측 로그와 불확실성**에 근거해야 한다. 후속 패치·현재 로스터를 적용하여 과거 경기를 재시뮬레이션하여 확정된 승패를 변경하거나, 확정 결과에 맞추어 존재하지 않았던 원인을 사후적으로 구성하지 않는다. [근거 #280](https://github.com/lkh0802a/LOL-GM/issues/280), [#239](https://github.com/lkh0802a/LOL-GM/issues/239)

### UI-008 · 현재 감독의 권한과 저장/화면 문맥
조회·스크롤·미리보기/목록 복귀는 세계 시간·AI 결정·계약·자금 원장을 수정하지 않는다. 오래된 세이브나 이전 관리 구단·선수를 대상으로 잔존하는 UI 콜백이 무단 계약/이적·저장을 실행하지 않아야 한다. [근거 #225](https://github.com/lkh0802a/LOL-GM/issues/225), [#240](https://github.com/lkh0802a/LOL-GM/issues/240)
