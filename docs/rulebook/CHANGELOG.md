# 규정집 변경 기록

## 편찬 원칙

- 여기에는 **사용자가 승인한 게임 규칙의 의미 변경 또는 출처 확인에 따른 정정**만 기록한다.
- GitHub PR을 단지 만들거나 병합한 사실은 **새 게임 규칙 승인**과 다르다. 기존 승인의 최초 편찬은 신규 정책으로 간주하지 않는다.
- 규정집 버전은 문서 편찬 버전이다. 실제 게임 속 지역/대회 규정의 `rulesVersion`/`effectiveSeasonId`와 별개다.
- 의미 변경 시 변경 전후 정의, 규칙 ID, 사용자의 **명시적 승인 링크**, 기존 계약/진행 대회에 대한 발효 범위를 반드시 남긴다. 새 승인이 없으면 개정하지 않는다.
- 과거 확정 기록을 삭제하지 않으며, 기술적 오탈자 정정은 의미 변경과 구분한다.

## 2026-11-01 — 재정 정산 간소화·현실성과 게임성 병행 v0.8.1

**유형: 사용자 직접 승인에 따른 BIZ-004의 의미 정밀화와 룰북 편찬 원칙 추가.** 사용자 근거: 2026-11-01 이 대화에서 '연체는 실제 자금 부족일 때만 남기고 정상 지급은 자동 처리, 복잡한 연체 미니게임은 두지 않는다'는 제안에 동의한 뒤, '간소화할 것은 간소화해서 작성', '게임성과 현실성을 같이 챙긴다'고 명시하였다. 이 대화에는 공개 GitHub 승인 댓글이 없으므로 승인 출처를 다른 과거 이슈 댓글로 가장하지 않는다.

- **이전 BIZ-004:** 계약·상금·후원·참가비 등 실거래 기록, 실제 지급·미지급, 계약 취소 책임과 이중 정산 금지만 기재. 정상 지급 자동 처리와 자금 부족 시 미지급의 구별은 정본에 구체적으로 정의하지 않았음.
- **현행 BIZ-004:** 지급기일이 도래한 유효 채무는 실제 사용 가능한 자금이 충분하면 **자동 정산**한다. AI의 근거 없는 지급 지연·시스템상의 지급 누락으로 인위적 연체를 만들어서는 안 된다. 실제 유동성 부족으로 미이행한 채무는 원장에 기록하고 신용·협상·재정난 등의 경제적 영향을 보존한다. 유예·이자·위약금·지급분쟁은 유효한 계약과 적용 규정에서 정한 범위만 적용한다.
- **효력과 제약:** [#251 130B 이적료 분할금 연체](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6245258798)와 [#251 185D 정기 환불 정산](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6246141985)을 폐기하지 않고 **지급 실행 방식만 간소화**한다. 법적으로 지급기한이 더 이르면 정기 배치가 그 기한을 넘겨서는 안 된다. 원자적 계약 성립 요건·선지급·바이아웃을 가짜 미지급 처리로 우회할 수 없고 확정된 이적·계약·경기 결과를 소급 취소하지 않는다. 허위 현금·중복 지급·반복 채권 추심/납부 클릭 콘텐츠를 만들지 않는다.
- **추가 간소화 후보:** 의료 일상 복귀, 소액 후원 계약 의무, 입장권 가격 책정, 굿즈 재고, 시설 이용, 스태프 업무/회의, 알림 집약, 단일 정산 통화 등은 [별도 승인·간소화 점검 기록](../RULEBOOK_APPROVAL_ADJUDICATION_2026_11_01.md)에서 원문과 현재 룰북 수록 여부를 구분한다. 이번 버전은 해당 기능의 실제 구현을 완료했다는 뜻이 아니며, 추가 정책을 묵시적으로 승인한 것도 아니다.
- **발효:** 정본의 향후 게임 세계 결정에 적용하는 편찬 규칙이다. 기존 실제 계약의 별도 지급기일/법적 권리/정산 이력은 유지한다. 런타임 코드·세이브·장기 경제 테스트·main 병합은 별도 검증 대상이다.
