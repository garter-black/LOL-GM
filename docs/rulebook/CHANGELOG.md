# 규정집 변경 기록

## 편찬 원칙

- 여기에는 **사용자가 승인한 게임 규칙의 의미 변경 또는 출처 확인에 따른 정정**만 기록한다.
- GitHub PR을 단지 만들거나 병합한 사실은 **새 게임 규칙 승인**과 다르다. 기존 승인의 최초 편찬은 신규 정책으로 간주하지 않는다.
- 규정집 버전은 문서 편찬 버전이다. 실제 게임 속 지역/대회 규정의 `rulesVersion`/`effectiveSeasonId`와 별개다.
- 의미 변경 시 변경 전후 정의, 규칙 ID, 사용자의 **명시적 승인 링크**, 기존 계약/진행 대회에 대한 발효 범위를 반드시 남긴다. 새 승인이 없으면 개정하지 않는다.
- 과거 확정 기록을 삭제하지 않으며, 기술적 오탈자 정정은 의미 변경과 구분한다.

## 2026-11-01 — 포맷 범위 교정 및 국제대회·재정 누락 이관 v0.4.0

**유형:** 기존 사용자 승인을 재검증해 명확히 하고 누락된 내용을 이관한 편찬 수정. 신규 게임 정책 승인이나 코드 구현을 의미하지 않는다.

- **COMP-006 (적용 범위 교정):** 공식 캘린더의 싱글/더블 허용은 **개별 엘리미네이션 브래킷의 탈락 조건**을 정하는 규칙이다. 서로 다른 스위스·조별·엘리미네이션 단계에서 발생한 패배 횟수를 합쳐 **대회 전체 2패 제한**을 적용한다는 뜻이 아니다. 정상 결승은 한 번만 진행하여 무패 결승 진출팀도 추가 reset을 받지 않는다. 양측 실격으로 우승자가 없는 결승의 실제 판정도 보호한다. [최신 싱글/더블 해석](https://github.com/lkh0802a/LOL-GM/issues/234#issuecomment-6340237032), [결승 reset 금지](https://github.com/lkh0802a/LOL-GM/issues/234#issuecomment-6340164667), [양측 실격 우승자 없음](https://github.com/lkh0802a/LOL-GM/issues/234#issuecomment-6381690538).
- **COMP-004 (누락된 충돌 해결):** 모팀·산하 2군 1부 동시 참가 제한만 적힌 문구에, 모구단 강등으로 발생하는 **동일 2부 충돌 시 산하팀 적법 매각/해체(R01D)**를 연결. [사용자 R01D 승인](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6247461134), [후속 유지 확인](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6337287799).
- **COMP-015 신규 이관:** 7개 공식 국제대회의 표시명/권역컵 MSI 미진출 선발 및 World Championship→Masters→Open **출전 자격 선정 순서**와 중복 방지. [최신 승인](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6460414410).
- **BIZ-013 신규 이관:** 샐러리캡·사치세 상위 5인 vs 플로어 실제 부담 전체 선수 급여의 상이한 산정 대상. [사용자 승인](https://github.com/lkh0802a/LOL-GM/issues/237#issuecomment-6337472531).
- **BIZ-014 신규 이관:** 다구단 소유 허용과 소유 그룹 유한 재원·실제 인수/지원 거래의 양립. [사용자 승인](https://github.com/lkh0802a/LOL-GM/issues/237#issuecomment-6337472531).

9개 분야 **96조항 문구·적용 범위 1차 일괄 대조**와 출처 정밀도 별도 감사 기록은 [비규범 의미 감사](../RULEBOOK_SEMANTIC_AUDIT_2026_11_01.md) 참고. 이 감사는 과거 610개 댓글·PR 289건의 최종 효력을 일괄 판정했다는 뜻이 아니다.

## 2026-11-01 — 확인된 구단 정책 추가 이관 v0.3.0

**유형: 기존 사용자 확정의 누락 이관(새 정책 승인 아님).** BIZ-011에 2026-10-21 **육성 구단 경제 보상 C안의 네 가지 경로**(합법적 이적/셀온, 실제 기여에 대한 복수 구단 보상, 실제 리그 예산 내 지원, 입단·후원 평가 반영)를 이관. 지급 비율·재원·자격 기간·발효 조건은 미확정으로 남기고 가짜 계약/이적료/지원금 및 이중 원장 금지. [사용자 직접 승인](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6312211558).

BIZ-012에 2026-10-28 **구단의 프로/아마추어 등 고정 배타적 유형 폐지**와 실제 계약·라이선스·참가권의 별도 판정을 이관. [사용자 확정 기록](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6461053117). 게임 소스 변경·CI 성공·병합을 주장하지 않는다.

## 2026-11-01 — 원본 후속 결정 오류 정정·승인 조항 이관 v0.2.1

**기존 확정 선택의 올바른 해석을 복원**한다. 최초 편찬의 PLAYER-006에서 #190A 실명 병행을 현행으로 잘못 채택한 오류를 #190 최종 재정정([원문](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6246200434))에 따라 교정했다. **다구단 소유 금지의 후속 B안 변경**([원문](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6336990133)), 주장 시스템 철회, 독립 개최사 자체 디비전, 지역 경계, 최신 규칙 소급 적용과 과거 결과 보존의 구분을 추가 이관했다.

**주의:** v0.1.0 기록의 '가상 실명+닉네임'은 당시 **잘못 편찬한 문구**이며 최종 승인 규칙이 아니다. 과거 오기 자체는 삭제하지 않고 이 정정에 연결한다. 규칙 변경 승인/코드 구현을 새로 수행한 것이 아니다.

**유형: 신규 결정 없이 기존 승인 원본의 추가 조항을 이관.** 국가별 게임·랭크/선수 공급 및 고정 재능 상한 금지(#251), 아마추어 배경과 공식 3부 구별(#311), 초기 7개 국제대회가 영구 최대치가 아님(#251), 허위 기술 사고 이벤트 금지(#242), 독립대회 성적과 명성 분리(#251), 감독 UX·저장 슬롯 삭제(#225/#273/#280) 등을 수록. **모든 승인 세부 기록의 전수 이관이 끝난 것은 아니다**. 원본별 미이관 확인은 [별도 감사표](../RULEBOOK_MIGRATION_AUDIT.md)에 기록.

## 2026-11-01 — 최초 편찬 v0.1.0

**유형: 기존 사용자 승인 내용의 독립 규정집 1차 집약, 신규 규정 없음.**

- `CORE`, `COMP`, `CAL`, `TRANS`, `PLAYER`, `MATCH`, `BIZ`, `GOV`의 **현행 상위·분야별 규칙만** 수록하고 각 조항에 원본 근거를 연결.
- 2026-10-28의 구형 **7일 독점 기간은 2026-10-29 후속 결정으로 대체**됨을 반영.
- 2026-10-18 확정된 세계 랭크 **1~5인 파티·RP/세계 순위·닷지 금지·가상 실명+닉네임**을 반영.
- 옛 2부 의무·세계 3스플릿/14구간·11월 선수 FA·월즈 후 14일 독점은 현행 정본으로 되살리지 않음.
- 승인 근거는 원래 GitHub 이슈/댓글에 남고, 개발 PR/구형 문서는 별개 역사·구현 자료로 유지.
- 이 발행본은 **상위 규칙의 첫 묶음**이며 모든 과거 세부 조항이 전수 이관됐다고 주장하지 않는다. 새로운 세부 항목을 편입하려면 실제 승인 원문을 대조해야 한다.
