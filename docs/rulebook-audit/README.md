# LOL-GM 승인 기록 전수조사: 1차 원본 색인 (비규범)

**조사 시점:** 2026-11-01 · **조사 방식:** GitHub REST에서 전체 일반 이슈 **39개**를 식별해 **모든 이슈 댓글 610개**의 원본 링크·첫 제목·조사 후보 표시를 누락 없이 수집했다. 이미 존재하는 메인 이슈 본문/사용자 코멘트는 **역사·원본**으로 유지한다.

- [113개 조항별 출처·효력 판정 대장](CLAUSE_DECISION_MATRIX_2026_11_01.md): 관련 원문 **부분대조 113개**, 정본 교정 대기 **0개(COMP-004 v0.6.1 반영)**, 심화 **판정 대기 0개(CORE-007 v0.7.0 승인 반영)**. 직접 댓글 링크 보유 **71개**와 그 외 **42개**는 별도의 출처 깊이 통계다.
- [실제 선택·후속 철회·최신 교정 근거](../RULEBOOK_APPROVAL_ADJUDICATION_2026_11_01.md): R01D(동일 2부 매각·해체)와 최신 적격 하위 부 행정 이동 허용의 적용 범위 등을 실제 승인 원문 대조로 판정한다. 이 목록은 모든 댓글/PR의 최종 효력 판정 완료 표시가 아니다.

**2026-11-01 최신 CORE-007 확정:** 공식 대회 체계의 차기 시즌 구조 개편, 독립 대회의 차기 회차 개편, 신규 독립 행사의 당해 시즌 적법한 개설을 구분한다. 사용자는 2026-11-01 대화에서 해당 제안을 승인했으며 [정본](../rulebook/00-CORE.md)과 [변경 이력](../rulebook/CHANGELOG.md), [판정 대장](CLAUSE_DECISION_MATRIX_2026_11_01.md)에 반영했다. '112개 부분대조'는 610개 원문 댓글·289개 과거 PR을 모두 개별 인증한 것이 아니다.

**2026-11-01 v0.8.0 최신 이관:** [COMP-018~021](../rulebook/10-COMPETITIONS.md)·[BIZ-015](../rulebook/60-BUSINESS.md)·[GOV-010~012](../rulebook/70-GOVERNANCE.md)의 8개 원문 승인 항목을 추가했다. 87C(동률 무조건 결정전)는 [87B 사용자 후속 정정](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6245024040)으로 철회된 역사적 선택이며 현행 규정이 아니다. 보호 라이선스 **최초 집단 발급**과 **기발급 이후 개별 실효**는 구분하고, 사후 규정 위반·징계 이벤트 [18번 철회](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6315371588)를 행정 재심에 재도입하지 않는다. 111개 관련 원문 부분대조가 원본 댓글 610건·PR 289건의 선택별 전수 효력 검증과 같지 않다는 점은 유지한다.

**2026-11-01 v0.8.1 게임성과 현실성 동시 보장:** [BIZ-004](../rulebook/60-BUSINESS.md) 정상 지급 자동 정산·현금 부족 시 실제 미지급·계약 책임 유지·무작위 연체/반복 조작 배제를 사용자 후속 승인에 맞춰 반영했다. 별도의 [9차 간소화 후보 판정표](../RULEBOOK_APPROVAL_ADJUDICATION_2026_11_01.md)에는 기존 승인 10개 유형을 '이미 정본 반영/부분 반영/세부 미이관'으로 구분했다. 111개 관련 원문 부분대조는 전체 610개 댓글·289개 PR의 최종 전수 효력 인증과 구별한다.

**2026-11-01 v0.9.0 신규 CORE-010:** [세계 공통 운영 규정](../rulebook/00-CORE.md)에 중요한 감독·구단·선수 결정의 적법한 권한과 일상 업무의 자동 위임을 구별하였다. [BIZ-004](../rulebook/60-BUSINESS.md)는 유효 채무의 자동 지급, 가용 현금 부족에 따른 미지급과 유효 계약상 책임을 단일 원본으로 유지한다. 재활·소액 후원·가격 책정·굿즈·시설·직원 회의·알림·정산 통화 등의 **추가 기존 승인 간소화 후보**는 [판정표](../RULEBOOK_APPROVAL_ADJUDICATION_2026_11_01.md)에 미이관·구현 단계까지 구별해 추적한다. 전체 112개 조항과 댓글 610개·과거 PR 289건의 승인 선택 전수 판정은 다른 범위다.

**2026-11-01 v0.10.0 신규 TRANS-011:** [시즌 중 지역별 이적창](../rulebook/30-TRANSFERS.md)은 공식 국제대회 기간을 우선 활용하되 지역사무국이 개장 여부·횟수·기간을 자율 공표한다. 이적 계약·상대 지역 권리·대회 등록·연말 통합 28일 시장은 별도 검증한다. [교차 문서 충돌 기록](CROSS_DOCUMENT_CONFLICT_AUDIT_2026_11_01.md) U-01을 별도 승인으로 해결했으나 코드 수용·전수 검증 완료로 취급하지 않는다. 현재 정본 **113개 조항**이며, 이 문서의 v0.8.x·v0.9.0 부분대조 수치들은 당시 판정 이력이다.

## 최종 효력 전수 판정의 미완료 범위

1. **39개 본문+610개 댓글의 출처 목록은 작성했지만**, 각 댓글 내부의 개별 선택 수백 건을 **최종 유효/폐기/미결/기존 룰북 중복**으로 전수 판정한 것은 아니다. 이 인덱스는 누락 방지 장치다.
2. 일반 이슈와 별개로 **과거 PR 289건의 본문·리뷰·코멘트**, 오래된 `docs/DECISIONS.md`의 사용자 확정 이력·이전 토론의 변경 근거까지 전량 판정한 상태가 아니다. PR에는 구현 메모와 승인 발언의 복사가 섞여 있으므로 전부 자동으로 규범에 편입하지 않는다.
3. 현재 [룰북](../rulebook/README.md) **113개 조항**은 승인된 상위·일부 세부 규칙이다. 세부 기록을 임의로 생략하거나 **미수록은 승인 부재**라는 결론을 내리지 않는다.
4. 분야별 미이관/재검토 대상은 [기존 이관 감사표](../RULEBOOK_MIGRATION_AUDIT.md)로 추적한다. 최신 후속 결정 검증 없이 규칙을 삭제하거나 새 숫자를 추정하지 않는다.

**실제 개별 효력 판정(1차 UI·거버넌스 및 후속 철회):** [원문 대조·승인/대체/보류 기록](../RULEBOOK_APPROVAL_ADJUDICATION_2026_11_01.md). 본문 색인만 수행한 항목과 구분해 관리한다. [#232](https://github.com/lkh0802a/LOL-GM/issues/232)의 잘못 재도입된 #190A 실명 병기 문구 역시 최신 사용자 직접 정정으로 교정하였다.

**다음 판정 순서:** 먼저 #251의 일괄 선택 표·추가 재정정/철회, #234의 후속 시장·대회·일정, #224/#225 계약/UI, #311/#316/#321/#323/#324의 분야별 승인. **조항 ID를 영구 보존**, 한 분야 파일과 CHANGELOG만 고치고 각 사용자 승인 근거를 기록한다. 이후 해당 분야 실제 코드와 런타임 acceptance를 검증한다.
